# Catium
Launcher Minecrafta z Modrinth, paczką FPS i konfiguracją RAM.

## Uruchomienie (dev)
    npm install
    npm start

## Wersja do udostępniania
    npm run dist      # powstaje dist/Catium Setup *.exe oraz wersja portable

Albo wrzuć projekt na GitHub i dodaj tag `git tag v0.1.0 && git push --tags` - GitHub Actions zbuduje .exe i doda do Releases.

Wymagania gracza: Java 21 (dla 1.21.x) i konto Microsoft z Minecraftem.
